# 計測結果（データベース）

Notion で「データベース：テーブル」を作成し、以下のプロパティを追加する。CI を 1 回実行するごとに 1 行追加する。

| プロパティ | 型 | 例・メモ |
|---|---|---|
| 名前 | タイトル | 例：Blacksmith / ウォーム / 1 回目 |
| 実行日時 | 日付 | 時刻を含める |
| ランナー | セレクト | GitHub 標準 / Blacksmith |
| vCPU | 数値 | 2 |
| キャッシュ | セレクト | なし（コールド）/ あり（ウォーム） |
| 待ち時間（秒） | 数値 | ジョブが開始されるまでの時間 |
| ビルド（秒） | 数値 | イメージのビルドジョブ |
| Lint（秒） | 数値 | |
| 静的解析（秒） | 数値 | |
| テスト（秒） | 数値 | |
| 全体（秒） | 数値 | ワークフロー全体 |
| 課金対象（分） | 数値 | 各ジョブの分数（切り上げ）の合計 |
| 単価（$/分） | 数値 | GitHub 標準 約 0.006（要確認）/ Blacksmith 0.004 |
| コスト（$） | 数式 | `prop("課金対象（分）") * prop("単価（$/分）")` |
| 結果 | セレクト | 成功 / 失敗 |
| 実行 URL | URL | GitHub Actions の実行ページ |
| メモ | テキスト | |

## 作っておくと便利なビュー

- **ランナー別**：「ランナー」でグループ化し、数値列の集計を「中央値」にする
- **条件別**：「キャッシュ」でフィルタし、コールドとウォームを分けて見る
- **グラフ**：横軸を「ランナー」、縦軸を「全体（秒）」の平均にした棒グラフ
